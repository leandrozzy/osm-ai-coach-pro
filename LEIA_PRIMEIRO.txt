COMO TESTAR NA VERCEL
1. Depois do commit na v2-development, abra a Vercel.
2. Projeto: osm-ai-coach-pro-cloud-v4.
3. Vá em Deployments.
4. Procure um deployment cujo Git branch/ref seja v2-development.
5. Ele deve aparecer como Preview, não Production.
6. Abra o URL do Preview.
7. Teste pelo menos:
   - abrir cada um dos 4 slots;
   - Config > API Gemini;
   - Config > Importar dados da V1;
   - enviar uma imagem/vídeo de partida;
   - conferir se leandrozzy foi identificado como seu lado;
   - conferir árbitro;
   - conferir força própria x rival;
   - corrigir manualmente um campo NI;
   - gerar tática;
   - conferir Desarme com árbitro vermelho/laranja;
   - copiar tática;
   - registrar resultado;
   - abrir Diretor Esportivo.

SE A VERCEL NÃO CRIAR PREVIEW AUTOMÁTICO
