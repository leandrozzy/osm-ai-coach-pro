COMO TESTAR NA VERCEL
1. Depois do commit na v2-development, abra a Vercel.
2. Projeto: osm-ai-coach-pro-cloud-v4.
3. Vá em Deployments.
4. Procure um deployment cujo Git branch/ref seja v2-development.
5. Ele deve aparecer como Preview, não Production.
6. Abra o URL do Preview.
7. Teste pelo menos:
   - abrir cada um dos 4 slots;
   - Config > API Gemini;
   - Config > Importar dados da V1;
   - enviar uma imagem/vídeo de partida;
   - conferir se leandrozzy foi identificado como seu lado;
   - conferir árbitro;
   - conferir força própria x rival;
   - corrigir manualmente um campo NI;
   - gerar tática;
   - conferir Desarme com árbitro vermelho/laranja;
   - copiar tática;
   - registrar resultado;
   - abrir Diretor Esportivo.

SE A VERCEL NÃO CRIAR PREVIEW AUTOMÁTICO

CORREÇÃO v2.0.1 - MIGRAÇÃO DA V1
---------------------------------
O Preview da Vercel possui domínio diferente da produção e, por segurança do navegador,
não consegue ler o localStorage do endereço antigo.

Para migrar:
1. Abra a versão ATUAL/produção.
2. Vá em Config > Backup > Exportar backup.
3. Salve o arquivo JSON no celular.
4. Abra a V2 Preview.
5. Config > Importar backup da V1.
6. Escolha o JSON exportado da versão atual.
7. A V2 converterá os 4 slots, histórico e dados compatíveis.

Não use "Importar backup" da V2 para esse primeiro arquivo antigo; use "Importar backup da V1".
